# Demo script template — mapped to your event's 5-minute structure

Fill in the brackets, then rehearse it TWICE, timed, before presenting.
The segment/timing structure below matches your event's own guidelines
doc — don't improvise a different structure on the day.

| Segment | Time | Presenter | Script |
|---|---|---|---|
| Introduction | 30s | [NAME] | "We're [team name]. The problem: [one sentence]. Our solution: [one sentence]." |
| Problem context | 30s | [NAME] | "[Who's affected], [what goes wrong today], [why it's costly/urgent]." |

## Live demo click path (rehearse this exact sequence)

1. Load the dashboard — **pause 1 second**, let the KPI numbers register
   visually before talking
2. Point at the AI Executive Summary — read ONE sentence of it aloud,
   verbatim, so the jury hears it's real generated text
3. Click **[your "wow" moment feature]** — narrate what's happening
   while it loads ("this is a live call to our multi-agent pipeline, not
   cached")
4. Show the result — point at ONE specific piece of output that proves
   it's grounded/real (an agent name, a specific number, a cited source)
5. [Optional] One more screen/interaction if time allows — don't add a
   second thing unless the first 4 steps reliably finish under 90s in
   rehearsal

## Backup plan if something breaks live

- If the backend is down/slow: the frontend falls back to realistic
  placeholder data automatically — keep talking, don't apologize or
  explain the failure unless directly asked
- If a specific feature breaks: skip to the next screen smoothly, don't
  troubleshoot on stage
- Have a screen-recording of a successful run saved as backup — worth
  10 minutes to record one tonight/this morning, in case live demo wifi
  or the LLM provider has a bad moment

## Rehearsal checklist

- [ ] Full run-through, timed, hits under 5 minutes total
- [ ] Every presenter knows their segment AND can answer one likely
      question about someone else's part (judges don't always ask the
      "right" person)
- [ ] Backup recording exists
- [ ] Laptop fully charged, demo doesn't depend on venue wifi if avoidable
